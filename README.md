This is taking temperature data from hobo loggers that were affixed to a stake at locations around range cay. Different Hobos were placed at different heights on the stake so we could look at temperature at different heights over time and infer if the hobos were submerged or not. We used this prior to the coral outplant experiment for Shelbys project to see if the mangrove prop roots at this location would be a good place to outplant corals. 

This did not end up working, we did not have consistent recording as some of the hobo loggers died
